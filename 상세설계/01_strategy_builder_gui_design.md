# 01. 레고형 전략 생성 GUI 상세 설계서

## 1. 목적

전략 생성 GUI는 사용자가 코딩 없이 주식 매매 전략을 레고 블록처럼 조립할 수 있게 하는 핵심 화면입니다.

이 화면의 목표는 다음입니다.

```text
전략 조건을 쉽게 선택한다.
조건을 문장형 카드로 이해한다.
매수/매도/필터/자금관리 조건을 명확히 분리한다.
전략을 저장하기 전 자연어 설명과 오류 경고를 확인한다.
```

---

## 2. 핵심 사용자 흐름

```text
1. 새 전략 만들기 클릭
2. 빈 전략 또는 템플릿 선택
3. 매수 조건 추가
4. 매도 조건 추가
5. 필터 조건 추가
6. 자금 관리 조건 설정
7. 전략 미리보기 확인
8. 전략 오류/경고 확인
9. 저장
10. 백테스트 실행 화면으로 이동
```

---

## 3. 화면 레이아웃

추천 레이아웃은 3열 구조입니다.

```text
┌──────────────────────────────────────────────┐
│ 전략명 / 저장 / 복사 / 백테스트 실행 / JSON 보기 │
├───────────────┬────────────────┬─────────────┤
│ 블록 팔레트    │ 전략 조립 영역    │ 설정/설명 패널 │
│               │                │             │
│ 가격          │ 매수 조건        │ 선택 블록 설정 │
│ 이동평균       │ 매도 조건        │ 전략 설명      │
│ 거래량         │ 필터 조건        │ 오류/경고      │
│ 보조지표       │ 자금 관리        │             │
│ 캔들          │ 백테스트 설정    │             │
└───────────────┴────────────────┴─────────────┘
```

## 5. 블록 팔레트

블록 팔레트는 사용 가능한 조건 목록을 카테고리별로 보여줍니다.

### 카테고리

```text
가격
이동평균
거래량
RSI
MACD
볼린저밴드
신고가/돌파
캔들
시장 필터
유동성 필터
매도
자금 관리
리스크 관리
```

### 블록 표시 원칙

개발자 용어가 아니라 문장형 이름을 사용합니다.

나쁜 예:

```text
price_vs_ma
volume_ratio
rsi_level
```

좋은 예:

```text
종가가 이동평균선보다 높을 때
거래량이 평균보다 N배 이상일 때
RSI가 N 이하일 때
```

---

## 6. 전략 조립 영역

전략 조립 영역은 다음 섹션으로 구성합니다.

```text
매수 조건
매도 조건
필터 조건
자금 관리
백테스트 기본 설정
```

### 매수 조건 예시

```text
[매수 조건]
조건 조합: 모든 조건 만족 AND

① 종가가 20일 이동평균선 위
② 거래량이 20일 평균의 2배 이상
③ RSI(14)가 70 이하
```

### 매도 조건 예시

```text
[매도 조건]
조건 조합: 하나라도 만족 OR

① 수익률이 +7% 이상이면 익절
② 손실률이 -3% 이하이면 손절
③ 10일 이상 보유하면 매도
```

---

## 7. 조건 카드 설계

각 조건은 카드 형태로 표시합니다.

```text
┌──────────────────────────────┐
│ 이동평균 조건                  │
│ 종가가 [20]일 이동평균선보다 [위] │
│                              │
│ [수정] [복사] [삭제]            │
└──────────────────────────────┘
```

카드를 클릭하면 오른쪽 설정 패널에서 상세 값을 수정합니다.

---

## 8. 조건 편집 패널

조건 편집 패널은 선택된 조건의 파라미터를 수정합니다.

예: 거래량 조건

```text
[거래량 조건 설정]

기준:
거래량

평균 기간:
[20] 일

비교 방식:
평균 대비 배수

조건:
거래량이 평균 거래량의 [2.0] 배 이상

설명:
최근 20일 평균 거래량보다 오늘 거래량이 2배 이상 많으면 조건을 만족합니다.
```

---

## 9. 전략 자연어 설명

전략 조립 중 실시간으로 자연어 설명을 생성합니다.

예시:

```text
이 전략은 상승 추세에 있는 종목 중에서 거래량이 급증하고 RSI가 과열되지 않은 종목을 매수합니다.

매수 후 수익률이 7% 이상이면 익절하고, 손실률이 -3% 이하이면 손절합니다.
또한 10일 이상 보유하면 강제로 매도합니다.

매일 최대 100만 원까지 매수하며, 예수금이 부족하면 수익률이 가장 낮은 보유 종목의 25%를 매도합니다.
```

---

## 10. 전략 검증 패널

전략 저장 또는 백테스트 실행 전에 오류와 경고를 표시합니다.

### 오류

```text
매수 조건이 없습니다.
매도 조건이 없습니다.
필수 파라미터가 비어 있습니다.
지원하지 않는 조건 타입이 포함되어 있습니다.
```

### 경고

```text
손절 조건이 없습니다.
거래대금 필터가 없습니다.
시장 지수 필터가 없습니다.
매수 조건이 너무 많아 거래 횟수가 적을 수 있습니다.
예수금 부족 시 처리 규칙이 없습니다.
```

## 11. 초보자 모드와 전문가 모드

### 초보자 모드

질문형 UI를 제공합니다.

```text
어떤 종목을 사고 싶나요?

[ ] 상승 추세에 있는 종목
[ ] 거래량이 급증한 종목
[ ] 많이 하락한 뒤 반등하는 종목
[ ] 신고가를 돌파한 종목
```

### 전문가 모드

카드형 블록 빌더를 제공합니다.

```text
조건 직접 추가
AND / OR 설정
필터 분리
자금 관리 설정
JSON 보기
```

MVP에서는 카드형 블록 빌더를 기본으로 하고, 복잡한 논리식 편집은 후순위로 둡니다.

---

## 12. 전략 템플릿

새 전략 생성 시 템플릿을 제공합니다.

```text
이동평균 골든크로스 전략
거래량 급등 돌파 전략
RSI 과매도 반등 전략
신고가 돌파 전략
눌림목 반등 전략
추세추종 스윙 전략
```

템플릿 선택 시 조건 카드가 자동 생성됩니다.

---

## 13. 저장 동작

저장 시 다음 데이터를 생성합니다.

```text
strategy.name
strategy.description
strategy_json
tags
favorite
created_at
updated_at
```

저장 전 반드시 JSON validation을 수행합니다.

```text
전략 검증 경고

JSON 보기
백테스트 실행 버튼
```
