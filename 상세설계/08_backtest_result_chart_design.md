# 08. 백테스트 결과 차트 및 리포트 UI 상세 설계서

## 1. 목적

백테스트 결과 화면은 사용자가 전략 성과를 직관적으로 이해하게 만드는 핵심 화면입니다.

이 화면은 단순 숫자 표시가 아니라 다음 질문에 답해야 합니다.

```text
전략이 돈을 벌었는가?
시장보다 나았는가?
손실 구간은 얼마나 컸는가?
어느 종목에서 잘 작동했는가?
언제 매수하고 언제 매도했는가?
예수금 부족은 언제 발생했는가?
```

---

## 2. 전체 결과 화면 구조

```text
┌──────────────────────────────────────────────┐
│ 백테스트 결과: 전략명                         │
│ 기간 / 대상 / 초기자금 / 실행일                │
├──────────────────────────────────────────────┤
│ 총수익률 | 최종자산 | MDD | 승률 | 거래횟수     │
├──────────────────────────────────────────────┤
│ [요약] [포트폴리오] [종목별] [거래내역] [자금관리] │
└──────────────────────────────────────────────┘
```

---

## 3. 요약 카드

첫 화면에는 핵심 지표를 카드로 보여줍니다.

```text
총 수익률
최종 자산
연평균 수익률
MDD
승률
거래 횟수
평균 보유일
벤치마크 대비 성과
```

예시:

```text
총 수익률: +84.2%
최종 자산: 18,420,000원
MDD: -18.5%
승률: 47.8%
거래 횟수: 312회
평균 보유일: 8.4일
```

## 5. 포트폴리오 전체 차트

포트폴리오 전체 탭에서는 전략 전체의 성과를 보여줍니다.

차트:

```text
총자산 곡선
전략 누적 수익률
벤치마크 비교
MDD 그래프
예수금 변화 그래프
보유 종목 수 변화
```

---

## 6. 종목별 상세 차트

사용자가 특정 종목을 선택하면 봉차트를 표시합니다.

```text
종목 선택: [삼성전자 ▼]

상단:
봉차트 + 이동평균선 + 매수/매도 마커

중단:
거래량 차트

하단:
전략 누적 수익률
종목 단순 보유 수익률
벤치마크 수익률
```

---

## 7. 봉차트 표시 원칙

봉차트 위에 수익률 숫자를 계속 표시하면 지저분해집니다.

따라서 기본 원칙은 다음입니다.

```text
봉차트 위에는 매수/매도 마커만 표시한다.
매도 수익률 라벨은 기본적으로 숨긴다.
필요 시 옵션으로 표시한다.
수익률은 하단 수익률 그래프에 일정 간격으로 표시한다.
상세 정보는 마우스 오버 툴팁으로 보여준다.
```

```text
매수:

회색 계열

예수금 확보용 일부 매도:

```

## 9. 툴팁 설계

### 일반 날짜 툴팁

```text
2024-06-14

종가: 72,500원
전략 누적 수익률: +18.4%
종목 단순 보유 수익률: +11.2%
벤치마크 수익률: +6.7%
보유 상태: 보유 중
평가 수익률: +4.3%
예수금: 1,240,000원
총자산: 11,850,000원
```

### 매수 마커 툴팁

```text
매수 체결

종목: 삼성전자
날짜: 2024-03-12
체결가: 72,000원
수량: 13주
매수 금액: 936,000원

매수 사유:
- 종가가 20일선 위
- 거래량이 20일 평균의 2배
- RSI 64.2
```

### 매도 마커 툴팁

```text
매도 체결

날짜: 2024-04-05
체결가: 78,200원
수량: 13주
수익률: +8.6%
손익: +80,600원
보유일: 17일
매도 사유: 익절
```

### 일부 매도 툴팁

```text
일부 매도

날짜: 2024-06-11
수량: 5주
매도 비율: 25%
사유: 예수금 부족
확보 현금: 410,000원
```

## 10. 수익률 라벨 간격

수익률 그래프에는 일정 간격으로만 라벨을 표시합니다.

옵션:

```text
표시 안 함
1개월
3개월
6개월
1년
```

기본값:

```text
6개월
```

---

## 11. 차트 표시 옵션 패널

```text
☑ 매수/매도 표시
☑ 이동평균선 표시
☑ 거래량 표시
☑ 전략 수익률 표시
☑ 벤치마크 수익률 표시
☐ 매 거래 수익률 라벨 표시
☑ 6개월 단위 수익률 라벨 표시

수익률 라벨 간격:
[6개월 ▼]
```

---

## 12. 거래 내역 연동

거래 내역 표에서 특정 거래를 클릭하면 차트가 해당 구간으로 이동합니다.

```text
거래 클릭
→ 해당 종목 선택
→ 매수일~매도일 주변으로 차트 확대
→ 매수/매도 마커 강조
```

---

## 13. 자금 관리 탭

로블랙님 프로그램의 차별화 화면입니다.

표시 항목:

```text
초기 자금
최종 자산
평균 예수금
최소 예수금
현금 부족 발생 횟수
현금 부족으로 매수 실패한 횟수
예수금 확보용 일부 매도 횟수
일부 매도로 확보한 총 현금
```

차트:

```text
예수금 변화 그래프
보유 평가금액 그래프
총자산 그래프
현금 부족 이벤트 표시
일부 매도 이벤트 표시
```
