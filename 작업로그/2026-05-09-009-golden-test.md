# Phase 1 / Step 9 — Golden Test (Phase 1 마무리)

## Plan

설계서 12번 15절의 Golden test fixture. 고정된 시세 + 고정된 전략 → 고정된 결과를 박아두고 매 빌드마다 회귀 검증. 부동소수 차이는 절대 1원 또는 1e-6 상대 오차 허용.

### 시나리오

- [ ] **golden_01_ma_cross_take_profit_stop_loss**:
  - 단일 종목, 90일 시계열 (deterministic seed)
  - 전략: price > MA(5) entry, take_profit 5% / stop_loss 3%
  - 검증: total_return / mdd / trade_count / win_rate 정확히 일치
  - 거래 N건의 entry/exit 가격이 동일해야 함

- [ ] **golden_02_with_exit_signal**:
  - 단일 종목, 60일 시계열
  - 전략: price > MA(5) entry, exit_signal: price < MA(5)
  - 익절/손절 없음 (지표 매도만)
  - trade_count + final_equity 일치

- [ ] **golden_03_determinism**:
  - 같은 시나리오 10회 반복 실행 → final_equity / trade_count 모두 동일
  - Python dict 순서 의존 없음 검증

  4. 의도 변경 시 expected 재생성 (PR 본문에 변경 이유 명시)

### 정책

- 모든 expected 값은 정수(가격) 또는 명확한 소수점 자릿수
- 부동소수 비교는 호가 단위(절대 1원) 또는 1e-9 상대 오차
- daily_equity 전체 비교는 비실용적 — 첫/마지막/중간 1~2개 샘플만
- trade_executions는 길이 + entry/exit 가격 + reason 비교

설계 결정:
- **Frozen expected는 1차 실행 결과 그대로 박음**: 의도적 변경 시 PR 본문에 expected 변경 사유 명시 + 새 값 산출. 의도하지 않은 변경 시 13번 정확성 정책 또는 계산식 회귀 의심.
- **합성 시계열은 log normal**: 실제 주가의 분포 특성에 가까움 + seed 고정으로 결정론.
- **OHLC 일관성**: high = max(open, close) × (1+u), low = min(open, close) × (1-u). 항상 high >= max(open, close) >= min(open, close) >= low.
- **부동소수 비교 abs 허용치**: final_equity는 1원, % 값은 0.001~0.01% 허용. 호가 단위 노이즈 회피.
