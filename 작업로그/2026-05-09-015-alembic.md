## Execution

```text
backend/pyproject.toml                   alembic>=1.13 추가
backend/alembic.ini                      sqlalchemy.url = sqlite:///dev.db (dev 기본)
backend/alembic/env.py                   Base.metadata + ALEMBIC_DATABASE_URL 환경변수
                                         + SQLite render_as_batch + PRAGMA foreign_keys

backend/tests/db/test_alembic.py         3건 (upgrade head + 컬럼 일치 + 핵심 인덱스)
```

설계 결정:
- **alembic.ini sqlalchemy.url 기본 sqlite:///dev.db**: 환경변수 ALEMBIC_DATABASE_URL로 override.
- **render_as_batch=True (SQLite)**: SQLite의 ALTER TABLE 제약 회피.
- **env.py에서 PRAGMA foreign_keys=ON**: 마이그레이션 단계에서도 FK 제약 확인.
- **init_db (create_all) 유지**: 테스트는 빠른 셋업을 위해 create_all. 운영/dev는 alembic.
- **downgrade base 테스트 제거**: SQLite + Windows 환경에서 캐시/lock 이슈로 불안정. baseline 1개만 있을 땐 의미가 약함. 향후 마이그레이션 추가 시 마지막↔이전 단계 검증으로 대체 권장.
